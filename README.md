# FloweryTalk

Heya! This project is a current WIP, I'll update the readme and make release pipelines when it's done so people can generate their own voice lines with Flowery's clips.

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

_A spiritual successor to [MorshuTalk](https://github.com/n0spaces/MorshuTalk)_

FloweryTalk is a portable command line tool which allows for speech synthesis from the Deltarune Chapter 5 character, [Flowery](https://deltarune.wiki/w/Flowery). Have you ever wished you could get Flowery to say anything you want? This is the project for you!
