# FloweryTalk

This project is very much still a WIP, check back when I cut a release :)

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

_A spiritual successor to [MorshuTalk](https://github.com/n0spaces/MorshuTalk)_

FloweryTalk is a portable command line tool which allows for speech synthesis from the Deltarune Chapter 5 character, [Flowery](https://deltarune.wiki/w/Flowery). Have you ever wished you could get Flowery to say anything you want? This is the project for you!

Note: Part of the joy I feel when I know something was made from MorshuTalk is that it kinda sounds [YTP-y](https://en.wikipedia.org/wiki/YouTube_Poop). If you're looking for smoothness, you might be thinking of someone synthesizing with a more machine-learning-ish tool. This tool is not that. I like to think that Flowery as a character would enjoy the concept of being clipped all around to say whatever people want him to say, instead of an ML-generated voice.

## Installation

If you're not a software developer kind of person, visit the [Releases Page](https://github.com/garypwhite/flowerytalk/releases/) and find the executable suitable to your operating system. I'll tag them appropriately. After this, you'll want to move the executable somewhere your system can easily find it.

This tool is exclusively a command line interface, so you should get familiar with what your [PATH](https://en.wikipedia.org/wiki/PATH_(variable)) variable is on your computer.
